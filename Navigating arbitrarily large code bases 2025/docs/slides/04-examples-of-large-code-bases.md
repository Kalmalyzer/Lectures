# Examples of large codebases

**Popular operating systems** - Windows (70 MLOC), MacOS (80 MLOC), Linux (kernel + drivers: 30 MLOC)

**Large applications/services** from companies like Microsoft or Google - Word, Excel, GMail

**"Business workflow tools"** - IBMs SAP

**Fully-featured web browsers** - Firefox, Chrome, Edge ( ~5 MLOC each)

**Large game engines** - Unreal, Unity, Snowdrop, Frostbite

**Large games** - Fortnite, Battlefield, CoD
